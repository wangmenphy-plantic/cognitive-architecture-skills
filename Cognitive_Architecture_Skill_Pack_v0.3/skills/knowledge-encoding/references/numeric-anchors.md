# Numeric Semantic Anchors

## Goal

让精确数字可以通过近似语义线索被找到，同时防止近似描述污染原始数字。

## Required separation

每个数字事实至少区分：

1. **原始值**：逐字、逐位保存。
2. **单位**：保留原单位及换算关系。
3. **上下文**：这个数字描述什么量、在哪个实验或情境出现。
4. **数量级锚点**：例如十、百、千、百万级。
5. **近似描述**：例如“约几百”“接近 0.7”。
6. **关系锚点**：比另一数值大/小、约为几倍、处于某范围。
7. **来源定位**：页码、表格、公式、版本或 URL。

## Example

```yaml
exact_value: 0.692
unit: "秒"
context: "某实验中问题呈现到开始作答的平均反应时"
magnitude: "亚秒级"
approximate_cues:
  - "大约七百毫秒"
  - "不到一秒"
  - "接近 0.7 秒"
relations:
  - "低于 1 秒"
source_locator: "论文印刷页 37；相应表格/段落"
```

示例中的数值仅示范字段关系；实际入库必须核对原始来源、统计量定义和单位。

## Rules

- 不能用四舍五入后的值替换原始值。
- 不将范围、平均值、中位数、标准差和最大值混为一谈。
- 不同单位必须显式转换，不能仅凭相近数字匹配。
- 搜索结果应显示精确值、单位、上下文和来源；近似匹配应标注“候选”。
- 数值线索不充分时询问额外线索或返回多个候选，不猜测唯一答案。
