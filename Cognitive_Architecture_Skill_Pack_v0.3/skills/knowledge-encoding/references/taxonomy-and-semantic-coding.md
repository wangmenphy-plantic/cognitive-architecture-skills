# Taxonomy and Semantic Coding

## Classification design

采用“稳定主分类 + 多值标签 + 关系网络”。主分类回答“归属哪里”，标签回答“有哪些特征”，关系网络回答“与什么有关系”。不要把所有关系都挤进目录树。

建议顶层分类示例：

- 数学：分析学、代数学、几何学、拓扑学、概率统计、数值计算。
- 认知训练：心算、逻辑推理、记忆、模式识别、策略选择。
- 技术知识：软件、工具、工作流、设备和技术细节。
- 方法与经验：学习策略、问题解决策略、错误教训。

这是可调整的起始分类，不是强制学科体系。新内容优先进入现有分类；只有出现稳定的新主题时才新增主分类。

## Chunking criteria

一个知识块应满足：

1. 有可识别的主题或问题。
2. 具有相对完整的意义。
3. 可以被独立提问或调用。
4. 能够连接到其他知识块。

定义、定理条件和结论不可为了缩短而拆散；长证明可拆成多个步骤，但必须保留证明整体的结构链接。

## Semantic coding fields

为每个知识单元形成多种表达入口：

- 规范术语；
- 自然语言释义；
- 用户自己的表述；
- 常见提问方式；
- 典型应用情境；
- 邻近概念；
- 容易混淆的概念。

语义锚点只是线索，不替代规范定义。

## Discriminative coding

遇到相似概念，建立一张对照记录：

| 字段 | 说明 |
|---|---|
| 共同特征 | 为什么容易混淆 |
| 关键区别 | 最小但充分的区分条件 |
| 反例 | 哪个例子能暴露区别 |
| 常见误判 | 用户曾经或可能犯的错 |
| 检索提示 | 如何从线索提取正确概念 |

## Versioning

当定义或事实被修正时，不直接静默覆盖旧值。保留来源与版本变化；如果新旧内容分别适用于不同约定或条件，则建立两个独立单元并说明差异。
