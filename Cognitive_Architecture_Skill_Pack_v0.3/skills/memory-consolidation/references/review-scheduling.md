# Review Scheduling

## Starting policy

在没有足够个人数据前，使用简单的试运行计划：

- 初次学习结束：一次简短无提示回忆。
- 下一次学习开始：用少量时间回顾前次核心知识。
- 后续若能独立准确提取：逐渐拉长复习间隔。
- 若只能在提示下恢复：缩短间隔，并调整语义线索。
- 若反复混淆：加入对比、反例和情境辨析。

## Adaptive adjustment

| 表现 | 调整建议 |
|---|---|
| 无提示准确且能应用 | 延长间隔，改用迁移题抽查 |
| 无提示部分正确 | 保持或略缩短间隔，针对遗漏提取 |
| 需要较强提示 | 缩短间隔，检查编码和检索线索 |
| 与相似概念混淆 | 增加区分性训练，不只重复定义 |
| 完全无法回忆 | 先重建理解和编码，再安排短间隔回忆 |

## Important limitation

不要声称某一固定间隔是该用户的最优间隔，除非有足够持续数据和验证。复习计划是可更新的工作假设，不是对遗忘曲线的个人诊断。
