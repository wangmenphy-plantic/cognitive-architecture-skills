# Recall Protocol

## Standard retrieval test

1. 指定知识范围和任务类型。
2. 明确用户暂时不看笔记、不看 AI 总结。
3. 提出一个开放问题，让用户自由回忆。
4. 记录原始回答，不先纠错。
5. 根据缺失内容提供最小提示。
6. 让用户再次组织完整答案。
7. 对照来源核验。
8. 记录提示等级和具体遗漏。

## Recall scoring

| Level | 操作性描述 |
|---|---|
| R0 | 无法回忆或只认得主题 |
| R1 | 需要明确提示才能恢复主要内容 |
| R2 | 凭模糊语义线索恢复部分内容 |
| R3 | 无提示恢复主要结构，但有明显遗漏或较慢 |
| R4 | 无提示、准确恢复关键内容和条件 |
| R5 | 能准确提取并在新问题中灵活调用 |

R0—R5 是项目内部记录尺度，不是临床或标准化心理测量。

## Distinguish retrieval from recognition

- 看到答案后说“我认识”属于再认，不等于自主回忆。
- 从选项中选对不等于能够独立生成答案。
- 复述大意不等于准确掌握数学定义或公式。
- 用户能解释适用条件并在新题中使用，提供了比单纯熟悉感更强的掌握证据。

## Interference drill

对容易混淆的知识，交错提出：

1. A 的定义是什么？
2. B 的定义是什么？
3. 两者共同点是什么？
4. 最小区别是什么？
5. 给出一个能区分 A 与 B 的例子或反例。

每道题单独记录，不因一题答对就推断全部掌握。
