# Training Modes and Task Design

## 1. Non-visual reasoning

训练流程：

1. 用户用语言或符号复述问题。
2. 列出已知条件和目标。
3. 判断条件间的依赖关系。
4. 选择可用定义、定理或推理规则。
5. 独立推进关键步骤。
6. 检查每一步是否由前提支持。

训练变量可包括：条件数量、依赖链长度、干扰条件、隐含条件、抽象程度。一次只增加一个主要变量。

## 2. Mental calculation

区分以下能力：

- 基础算术事实的快速提取；
- 数字分块；
- 数字关系识别；
- 特殊模式或规律识别；
- 计算策略选择；
- 中间结果保持与输出；
- 最终结果检查。

一次练习最好记录用户实际采取的路径，而不是只记录最终答案。对于口头题和视觉题，应分别标注呈现条件，因为记忆负担不同。

## 3. Pattern and strategy selection

每道题结束后问：

- 你最先注意到什么特征？
- 它让你联想到什么熟悉子问题？
- 选择了哪种策略？
- 是否存在更简单的策略？
- 在什么条件下当前策略会失效？

不要因为某种策略对某题更快，就断言它对整个题型都更优。

## 4. Knowledge application and transfer

由近到远设计迁移：

1. 相同结构、表面数字变化。
2. 相同原理、表达形式变化。
3. 相同定理、对象或上下文变化。
4. 多个知识块组合的新问题。
5. 用户自己判断何时调用该知识。

记录迁移距离和成功情况，不只写“迁移成功”。

## 5. Difficulty adjustment

优先使用小幅调整：

- 增加一项条件；
- 延长一步推理链；
- 改变题目表达；
- 减少提示；
- 加入一个相似干扰项；
- 将熟悉模式嵌入更大问题。

若连续失败，降低一个维度并分析原因，不要简单重复同难度任务。
