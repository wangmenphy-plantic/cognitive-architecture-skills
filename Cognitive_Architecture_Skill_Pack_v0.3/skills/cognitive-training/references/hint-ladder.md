# Hint Ladder — H0 to H5

| Level | 提示 | 允许内容 |
|---|---|---|
| H0 | 无提示 | 只呈现任务，等待用户独立尝试 |
| H1 | 领域提示 | 提醒相关知识分类、定义或工具类别 |
| H2 | 关键线索 | 指出一个值得观察的性质或关系 |
| H3 | 下一步方向 | 指出接下来需要建立的关系或检查的条件 |
| H4 | 局部演示 | 展示一个关键推理/计算步骤，不给完整解答 |
| H5 | 完整讲解 | 完整思路、计算过程、验证与总结 |

## Rules

- 默认 H0。用户明确要求直接解释时可直接 H5，不必强迫走完整阶梯。
- 每次升级只增加一个必要信息。
- 用户自行完成之后，要求其用自己的话复述关键思路。
- 记录“最高使用提示等级”和“是否独立完成”。
- H1 或 H2 后正确完成，不应记作完全无提示掌握。
- 提示等级是本项目的操作性设计，不是论文原有量表。

## Example

用户卡在证明中：

- H1：“回忆连续映射的定义中，开集的原像有什么性质？”
- H2：“尝试把目标集合写成一个开覆盖。”
- H3：“你需要利用紧致性对这个开覆盖做什么？”
- H4：展示如何选取有限子覆盖的一步。
- H5：完整说明证明并检查所有条件。
