# Source Grounding — Skill and Skilled Memory (1990)

## Bibliographic record

James J. Staszewski, *Skill and Skilled Memory: Final Report*, Research Report 04206, 18 February 1990. The report summarizes two longitudinal studies: digit-span skill acquisition and mental-calculation skill acquisition.

## Source-derived ideas used in this pack

1. **Mnemonic Storage Principle**: acquired semantic structures allow familiar patterns to be encoded as meaningful chunks.
2. **Retrieval Structure Principle**: information is indexed in a stable organization that supports orderly later retrieval.
3. **Speed-Up Principle**: practice improves the speed and reliability of encoding, indexing and retrieval.
4. In DD's digit-span skill, the report analyses three interacting mechanisms: semantic coding system, retrieval structure and contextual coding system.
5. Contextual coding includes relations that can distinguish similar or redundant codes and reduce interference.
6. In mental calculation, familiar patterns are associated with local strategies; pattern recognition supports strategy selection. Retrieval can replace some computation, and strategies that produce fewer intermediate results may reduce interference.

## Report locations

- Printed pp. 15–18: hierarchical grouping and retrieval structures.
- Printed pp. 19–23: semantic categories, semantic network and cue-guided retrieval.

- Printed pp. 32–40: expert mental-calculation representations, pattern recognition and strategy selection.
- Printed pp. 46–48: practical implications for knowledge engineering and instructional design.

## Boundaries

The report is evidence about particular trained individuals and tasks. It does not directly test this AI Skill package, modern vector search, a general mathematical-proof curriculum, or unrestricted transfer across domains. The design in this package is an engineering translation and should be validated against the user's own performance records.
