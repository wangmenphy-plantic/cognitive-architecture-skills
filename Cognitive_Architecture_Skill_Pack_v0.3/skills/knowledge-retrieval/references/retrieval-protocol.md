# Retrieval Protocol

## Candidate search sequence

1. 精确词项：正式术语、符号、公式、来源 ID。
2. 同义与语义：用户自己的表述、通俗解释、典型问题。
3. 层级范围：主分类、子分类、相邻章节。
4. 关系扩展：前置知识、推广、特例、应用和对比项。
5. 情境线索：学习时间、教材章节、课堂任务、使用目的。
6. 候选验证：比较定义、条件、结果、数值和来源。

不要求每次严格按顺序执行。若用户提供明确公式编号，精确检索应优先。

## Confidence language

- **高匹配**：名称和关键特征一致，来源能够核验。
- **中匹配**：主要语义一致，但仍缺一项区分性信息。
- **低匹配**：仅有宽泛主题相似，不能当作答案。

不要输出伪精确的概率数值，除非搜索系统确实提供经过校准的分数。

## Retrieval as memory practice

训练场景的默认次序：

1. 用户先自行回忆。
2. AI 询问一个最有价值的线索。
3. AI 给出低等级提示。
4. 用户尝试恢复完整知识。
5. AI 搜索并核对。
6. 记录无提示成功、提示后成功或未能恢复。

## Avoid retrieval traps

- “听起来像”不等于定义等价。
- 同一术语在不同教材或领域可能含义不同。
- 公式符号可能被不同作者复用。
- 同一个数值可能对应不同统计量或物理量。
- 页面提取错误、OCR 错误或用户摘录错误必须标记待核验。
