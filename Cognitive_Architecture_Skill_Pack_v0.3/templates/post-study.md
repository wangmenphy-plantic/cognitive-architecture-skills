# Post-Study Review — 日常简化复盘

```text
【今日学习】

1. 今天最重要的三个知识点是什么？
   -
   -
   -

2. 我调用了哪些旧知识？它们与新知识有什么联系？

3. 今天遇到了什么困难或错误？哪些内容无法独立回忆？

4. 我发现了什么新模式、新策略或新规律？
```

## AI 处理步骤

1. 先核对用户自主回忆，不要先展示答案。
2. 区分完整回忆、部分回忆、错误和无法回忆。
3. 检查关键定义、条件、符号、公式、数字和单位。
4. 识别知识缺失、提取失败、概念混淆、策略错误、逻辑错误、计算错误或干扰。
5. 提议哪些内容应进入知识库，并给出分类与关联。
6. 更新训练记录；若无真实写入能力，提供待写入结构化记录。
7. 给出下一次 1—3 个重点。
