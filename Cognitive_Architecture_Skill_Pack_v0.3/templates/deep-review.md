# Deep Review — 阶段性认知复盘

```text
【阶段】
主题或章节：
时间范围：

一、知识编码
- 我能否独立提炼核心概念、条件和结论？
- 哪些知识块结构仍不清晰？

二、知识组织
- 新知识与哪些旧知识产生联系？
- 是否有新的分类或关系需要建立？

三、记忆提取
- 哪些知识能无提示准确回忆？
- 哪些需要语义线索或明确提示？
- 哪些容易与相似知识混淆？

四、认知执行
- 识别了什么模式？
- 选择了什么策略？
- 哪些推理或计算步骤仍不熟练？

五、错误分析
- 最典型的错误是什么？
- 根因已确认还是仅为假设？
- 应建立什么区分性线索？

六、后续训练
- 下一阶段最重要的 1—3 个目标是什么？
- 哪些知识需要复习或迁移测试？
```

## AI 输出要求

- 以实际任务和原始回答为证据。
- 将观察、用户自述和推断分开。
- 对比同类型、相近难度任务；不可比时说明限制。
- 不以新增知识条目数衡量人脑成长。
- 给出下一阶段的可检验计划，而不是泛泛鼓励。
